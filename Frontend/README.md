# Fasco PRO Frontend

Frontend application for the Fasco PRO management system, built with React and Vite.

## Stack

- React
- Vite
- JavaScript / JSX (no TypeScript)
- React Router (react-router-dom)
- Axios (HTTP client foundation)

## Prerequisites

- Node.js (v18 or newer recommended)
- npm

## Install

```bash
npm install
```

## Development server

```bash
npm run dev
```

Starts the Vite development server. Visit the printed local URL in your browser.

## Build

```bash
npm run build
```

Produces an optimized production build in `dist/`.

## Lint

```bash
npm run lint
```

Runs ESLint over the source files.
